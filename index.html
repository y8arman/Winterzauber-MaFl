⚙️ Setup

🚀 Fürs Team veröffentlichen – nur diese eine Datei

  1. Firebase-Projekt anlegen (console.firebase.google.com). Authentication → E-Mail/Passwort aktivieren. Firestore Database erstellen (Standort z. B. europe-west6 Zürich).
  2. Projekteinstellungen → Allgemein → Web-App hinzufügen. Die Werte apiKey, authDomain, projectId und appId in dieser Datei bei firebaseConfig eintragen (Datei im Editor öffnen, nach «firebaseConfig» suchen).
  3. Firestore → Regeln: die Regeln unten kopieren, einfügen und Veröffentlichen klicken.
  4. GitHub: neues Repository → «Add file → Upload files» → diese Datei als index.html hochladen → Settings → Pages → Branch main, Ordner / (root) → Save. Die URL lautet https://<konto>.github.io/<repo>/.
  5. Firebase → Authentication → Einstellungen → Autorisierte Domains: <konto>.github.io hinzufügen.
  6. App öffnen, registrieren, E-Mail bestätigen. In Firestore die Sammlung admins anlegen: Dokument-ID = eigene E-Mail in Kleinbuchstaben, Feld z. B. role: "admin". Neu anmelden – jetzt ist die Organisation fürs Wichteln sichtbar.
  7. Updates: die geänderte index.html im Repository erneut hochladen. Nach etwa einer Minute ist sie live.

Die Firebase-Werte in der Datei sind öffentliche Kennungen, keine Geheimnisse. Die Daten werden durch die Regeln geschützt.
